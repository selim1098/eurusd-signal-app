# EUR/USD Signal Pro Advanced Starter
- Demo/Live selector and configurable timeframe (M1 to D1)
- EMA/RSI settings, risk limits, SL pips, RR, refresh preference
- Settings saved locally on device
- Candle pattern educational guide
- APK build workflow

IMPORTANT: This starter does NOT connect to live market data, calculate indicators from real OHLC candles, or send MT5 orders. Auto-trading is disabled. Live mode is only a selector until a real provider and secure MT5 bridge are implemented and tested. Never enter broker passwords in this app.

Build: npm install; npm run build; npx cap add android; npx cap sync android.
